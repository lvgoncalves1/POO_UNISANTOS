<h2>📖 Sobre o Projeto</h2>

O **BibliotecAI** é um sistema de biblioteca virtual desenvolvido para instituições de ensino superior, com o objetivo de facilitar o gerenciamento de livros, usuários e empréstimos.

O projeto foi desenvolvido como atividade acadêmica da disciplina de **Programação Orientada a Objetos (POO)** da Universidade Católica de Santos (UNISANTOS).

A aplicação utiliza conceitos fundamentais de orientação a objetos, como:

- Encapsulamento;
- Herança;
- Associação, agregação e composição;
- Responsabilidade das classes;
- Regras de negócio;
- Organização e reutilização de código.

<br>

---

<br>

<h2>✨ Funcionalidades</h2>

O sistema contempla as seguintes funcionalidades:

- 📚 **Gerenciamento de livros:** cadastro e consulta do acervo.
- 👥 **Gerenciamento de usuários:** alunos e bibliotecários.
- 📖 **Empréstimos:** realização de empréstimos de livros.
- 🔄 **Devoluções:** registro e controle das devoluções.
- 🔎 **Disponibilidade:** consulta de livros disponíveis.
- 📋 **Controle de empréstimos:** acompanhamento dos empréstimos realizados.
- 🔒 **Regras de negócio:** validações e restrições para empréstimos e devoluções.

<h2>⚙️ Instalação e Configuração</h2>

Para executar o projeto localmente, siga as etapas abaixo.

<br>

<h3>1. Pré-requisitos</h3>

Antes de iniciar, certifique-se de possuir:

- Python 3.x
- Git
- Pip (gerenciador de pacotes do Python)

<br>

<h3>2. Clonar o Repositório</h3>

Clone o projeto utilizando o Git:

```bash
git clone https://github.com/lvgoncalves1/POO_UNISANTOS.git
```

Acesse o diretório:

```bash
cd POO_UNISANTOS
```

<br>

<h3>3. Criar um Ambiente Virtual</h3>

Recomenda-se utilizar um ambiente virtual para isolar as dependências.

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

<br>

<h3>4. Instalar as Dependências</h3>

Execute o comando:

```bash
pip install -r requirements.txt
```

Caso o Flask não esteja instalado:

```bash
pip install flask
```

<br>

<h3>5. Executar a Aplicação</h3>

Inicie o sistema:

```bash
python main.py
```

Após iniciar o servidor, acesse o endereço informado no terminal.

Na configuração padrão do Flask:

```text
http://127.0.0.1:5000
```

<h2>🧪 Testes Automatizados</h2>

O projeto utiliza o **Pytest** para validar o funcionamento das regras de negócio.

Para executar os testes:

```bash
python -m pytest
```

Os testes podem abranger:

- Validação de empréstimos;
- Controle de disponibilidade;
- Regras de devolução;
- Restrições de empréstimos simultâneos;
- Comportamentos das classes do domínio.
